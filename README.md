# 🩺 Diabetes Health Indicator Dashboard – Tableau Project

## 📊 Project Overview

This project visualizes diabetes-related health indicators using **Tableau**. The aim is to explore relationships among key medical attributes and highlight patterns in diabetic vs. non-diabetic individuals. It leverages visual storytelling to uncover trends and empower healthcare decisions.

## 🧠 Objective

To build an **interactive and insightful dashboard** that enables:
- Quick identification of diabetic risk factors
- Comparative analysis between diabetic and non-diabetic groups
- Exploration of patterns in features such as glucose level, BMI, and age

## 🗂️ Dataset

The data used in this project includes:
- **Pregnancies**
- **Glucose levels**
- **Blood pressure**
- **Skin thickness**
- **Insulin levels**
- **BMI (Body Mass Index)**
- **Diabetes Pedigree Function**
- **Age**
- **Outcome** (1 = Diabetic, 0 = Non-Diabetic)

Source: [Pima Indians Diabetes Dataset](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)

---

## 📌 Features of the Dashboard

- **Filters** for dynamic selection based on outcome (diabetic/non-diabetic)
- **Bar charts and histograms** for distribution comparisons
- **Box plots** to observe outliers in BMI and glucose levels
- **Heatmaps** to assess correlation across medical attributes
- **Age distribution** and impact on diagnosis
- **Outcome summary** using KPI cards and color-coded indicators

---

## 🛠️ Tools Used

- **Tableau**: Core tool for data visualization
- **Excel**: Data cleaning and transformation
- **Calculated Fields**: For custom metrics and categorization

---

## 🧩 Key Insights

- High glucose and BMI levels are **strongly associated** with diabetic outcomes
- Individuals aged **30+** show a significantly higher diabetic risk
- Diabetic patients have **lower insulin variability**
- Clear pattern of risk escalation with age, BMI, and glucose
